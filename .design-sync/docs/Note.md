Aside block — small muted text behind a 2px `--signal` left rule with a faint signal wash. An editorial-illustration primitive: use it for asides and caveats inside a figure. For a message that belongs to the screen (a caveat, an error, a result) use ui's `Callout`; errors are `defect`, never this.

```jsx
<Note>Assumes the target is planar to within 0.1 mm.</Note>
```
